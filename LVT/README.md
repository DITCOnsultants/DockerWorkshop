# Leuk Voor Thuis
In deze mappen staan diverse docker images die leuk/handig kunnen zijn voor een thuis-labje. Per map is er een docker-compose file beschikbaar die alles voor je in orde maakt.

Door `docker-compose up -d` te draaien in een map zal hij de container(s) op brengen en in de docker-compose file is terug te vinden op welke poort je je webbrowser moet richten om de applicatie te gebruiken (in dit geval zijn alle containers web-applicaties)
